# Contact Book

A Python command-line application for managing contacts

## Features

- Add Contacts
- View Saved Contacts
- Delete Contacts
- Validate Phone Numbers
- Prevent Duplicate Phone Numbers
- Save Contacts in a `.txt` file

## Technologies

- Python 3
- Python Standard Library

## How To Run

```bash
python contact_book.py
```

> Note: The application interface is currently in Portuguese.
